# Criterios de auditoría

Califica cada criterio de 0 a 10. El total se pondera para dar un puntaje sobre 100.

| # | Criterio | Peso | Qué mirar |
|---|---|---|---|
| 1 | Largo y carga del chat | 20 | Número de turnos, archivos o documentos grandes pegados, salidas largas de herramientas. Si los primeros mensajes ya no se ven completos o hay un resumen automático en vez de ellos, máximo 4/10. |
| 2 | Temas mezclados | 15 | Cuántos temas distintos conviven en el mismo chat. 1 tema = 10. 2–3 relacionados = 7. 4+ o sin relación entre sí = 3 o menos. |
| 3 | Decisiones respetadas | 20 | ¿Las respuestas recientes siguen lo que se decidió antes? Cada decisión olvidada o contradicha baja 2–3 puntos. |
| 4 | Correcciones del usuario | 15 | Cuántas veces el usuario tuvo que repetir una instrucción, corregir lo mismo o decir "ya te dije". 0 = 10; 1–2 = 7; 3–5 = 4; más = 1. |
| 5 | Contradicciones propias | 15 | Respuestas tuyas que dicen lo contrario de una anterior sin explicar el cambio. |
| 6 | Calidad de las últimas respuestas | 15 | Compara las últimas 3–5 respuestas con las primeras: ¿más genéricas, más repetitivas, menos específicas al proyecto, más errores? |

## Cálculo

Puntaje total = suma de (nota del criterio × peso) / 10.

Ejemplo: notas 4, 3, 6, 7, 8, 5 → (4×20 + 3×15 + 6×20 + 7×15 + 8×15 + 5×15)/10 = 54.5 → 55/100.

## Semáforo

- 🟢 **Verde (75–100)**: el chat está sano. Se puede seguir.
- 🟡 **Amarillo (50–74)**: ya hay pérdida. Conviene handover pronto, sobre todo antes de decisiones importantes.
- 🔴 **Rojo (0–49)**: el chat ya no es confiable. Handover y chat nuevo.

**Regla de corte:** si el criterio 3 (decisiones respetadas) o el 1 (largo) sacan 3 o menos, el semáforo es rojo sin importar el total. Olvidar decisiones o no ver el inicio del chat es lo que más daño hace.

## Honestidad

- Cada nota necesita evidencia concreta (qué turno, qué tema, qué decisión).
- No hay un contador exacto de capacidad: el puntaje sale de señales observables. Dilo una vez.
- No infles ni desinfles notas para justificar el handover.
